Workout Tracker API

RESTful API Documentatie voor het beheren van workouts en exercises

Interfaces

Gebruik deze interfaces om direct met de API te werken:

Workouts Manager Exercises Manager Statistics Dashboard

Overzicht

Deze API stelt je in staat om workouts en oefeningen te beheren. Je kunt nieuwe workouts toevoegen, bestaande workouts bijwerken, oefeningen aan workouts koppelen en meer.

Base URL: http://localhost:3000/api

Response Format

Alle responses zijn in JSON format en bevatten een success veld:

{
  "success": true,
  "data": { ... },
  "message": "Success message"
}

Workout Endpoints

GET /api/workouts
Haal alle workouts op

Response Voorbeeld:

{
  "success": true,
  "data": [
    {
      "id": 1,
      "name": "Morning Cardio",
      "date": "2025-12-01",
      "duration": 30,
      "type": "cardio",
      "created_at": "2025-12-01T08:00:00.000Z",
      "updated_at": "2025-12-01T08:00:00.000Z"
    }
  ]
}
GET /api/workouts/:id
Haal een specifieke workout op via ID

Parameters:

Naam Type Beschrijving
id number Het ID van de workout

Response Voorbeeld:

{
  "success": true,
  "data": {
    "id": 1,
    "name": "Morning Cardio",
    "date": "2025-12-01",
    "duration": 30,
    "type": "cardio",
    "created_at": "2025-12-01T08:00:00.000Z",
    "updated_at": "2025-12-01T08:00:00.000Z"
  }
}
POST /api/workouts
Maak een nieuwe workout aan

Request Body:

Naam Type Verplicht Beschrijving
name string Ja Naam van de workout
date date Ja Datum (YYYY-MM-DD)
duration number Ja Duur in minuten
type string Ja Type: cardio, strength, flexibility, sports, mixed

Request Voorbeeld:

{
  "name": "Evening Run",
  "date": "2025-12-12",
  "duration": 45,
  "type": "cardio"
}

Response Voorbeeld:

{
  "success": true,
  "message": "Workout created successfully",
  "data": {
    "id": 5,
    "name": "Evening Run",
    "date": "2025-12-12",
    "duration": 45,
    "type": "cardio"
  }
}
PUT /api/workouts/:id
Update een bestaande workout

Parameters:

Naam Type Beschrijving
id number Het ID van de workout

Request Body: (zelfde als POST)

Response Voorbeeld:

{
  "success": true,
  "message": "Workout updated successfully"
}
DELETE /api/workouts/:id
Verwijder een workout

Parameters:

Naam Type Beschrijving
id number Het ID van de workout

Response Voorbeeld:

{
  "success": true,
  "message": "Workout deleted successfully"
}

      "id": 1,
      "workout_id": 2,

      "sets": 4,
      "reps": 8,
      "weight": 80.00,

      "workout_date": "2025-12-02",
      "created_at": "2025-12-02T10:00:00.000Z",
      "updated_at": "2025-12-02T10:00:00.000Z"
    }
  ]
}
GET /api/exercises/workout/:workoutId
Haal alle exercises van een specifieke workout op

Parameters:

Naam Type Beschrijving
workoutId number Het ID van de workout
GET /api/exercises/:id
Haal een specifieke exercise op via ID

Parameters:

Naam Type Beschrijving
id number Het ID van de exercise
POST /api/exercises
Maak een nieuwe exercise aan

Request Body:

Naam Type Verplicht Beschrijving
workout_id number Ja ID van de workout
name string Ja Naam van de oefening
muscle_group string Ja Spiergroep: chest, back, legs, shoulders, arms, core, full_body
sets number Ja Aantal sets
reps number Ja Aantal herhalingen
weight number Nee Gewicht in kg (optioneel)

Request Voorbeeld:

{
  "workout_id": 2,
  "name": "Squat",
  "muscle_group": "legs",
  "sets": 5,
  "reps": 5,
  "weight": 100.00
}

    "name": "Squat",
    "muscle_group": "legs",

Parameters:

Error Responses

Bij fouten retourneert de API een error response met details:

{
  "success": false,
  "message": "Error message",
  "error": "Detailed error description (in development mode)"
}

HTTP Status Codes

Code Betekenis
200 OK - Succesvol verzoek
201 Created - Resource succesvol aangemaakt
400 Bad Request - Ongeldige data
404 Not Found - Resource niet gevonden
500 Internal Server Error - Server fout
